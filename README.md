# Fatos Básicos

Treino dos fatos básicos da matemática — contas de 1 dígito de soma, subtração, multiplicação e divisão — contra o relógio, para crianças.

- 50 contas por nível, 2 minutos, 4 alternativas
- Avança de nível com 90% de acertos (45 de 50)
- Operações liberadas em ordem: soma → subtração → multiplicação → divisão
- Progresso salvo no navegador

É uma página única: basta abrir o `index.html`.
